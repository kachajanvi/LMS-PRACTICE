# Employee Management System using OOP

## 📌 Project Overview
This project is a simple Employee Management System developed in Python using Object-Oriented Programming (OOP). It allows users to add and manage different types of employees through a menu-driven program.

## ✨ Features
- Add Person
- Add Employee
- Add Manager
- Add Developer
- Show All Employees
- Search Employee by Name
- Menu-Driven Interface

## 🛠️ OOP Concepts Used
- Classes and Objects
- Inheritance
- Method Overriding
- Encapsulation
- Polymorphism
- super() Function

## 📂 Classes
- Person (Base Class)
- Employee (Derived Class)
- Manager (Derived from Employee)
- Developer (Derived from Employee)

## 💻 Technologies Used
- Python 3
- Python IDLE

## ▶️ How to Run
1. Open the project in Python IDLE.
2. Run the Python file.
3. Choose an option from the menu.
4. Enter the required details.
5. View or search employee records.

## 📋 Menu Options
1. Add Person
2. Add Employee
3. Add Manager
4. Add Developer
5. Show All Employees
6. Search by Name
7. Exit
